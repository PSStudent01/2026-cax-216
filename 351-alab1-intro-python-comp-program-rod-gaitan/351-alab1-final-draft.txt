1. What is computer programming, and why is it important in today's technology-driven world?
Computer programming is the process of writing instructions in code that tell a computer exactly what to do, step by step, to perform a task or solve a problem. It pretty much translates human logic language into a language machines can understand.

It's important today because pretty much everything that we interact with on a daily basis, runs on software. For example, phones, banking systems, medical devices, cars, communications. Programming is the skill that lets people build and improve these systems, which makes it essential in our modern day world.

#
2. What is Python, and one reason it's popular for beginners?
Python is a high-level, general-purpose programming language known for being readable and relatively easy to learn. One major reason it's popular with beginners is it's simple syntax because it reads almost like plain English, which allows new programmers to focus on learning logic and problem-solving rather than having to worry about complex syntax rules.

#
3. What do you need to start writing and running Python programs on your computer?
- Python installed on your computer, which you can download from 'python.org', the 'interpreter' being the more important component that actually runs your code.
- A code editor or IDE to write your code. For example:
-- Python's IDLE, which comes bundled with Python 
-- or VS Code, which comes with a Python extension.
- Maybe even a terminal/command line to quickly test a command, script
