Fix:
That’s the crash I expected: PermissionError: [Errno 13] Permission denied: 'tasks.csv', raised at the open(filename, "w", ...) line in save_tasks. It also confirms the read-only setting worked. Keep this traceback as your “before” capture.

Why it crashed. Your load_tasks has try/except blocks, but save_tasks has none. When open(..., "w") failed, nothing caught the error, so it travelled up through main() and ended the program, which is what the chain of File ... lines shows. Python’s PermissionError is a subclass of OSError, which is why one except OSError will catch it and other file problems like a full disk.

The fix. Wrap the body of save_tasks in a try/except. You already wrote the same pattern in load_tasks, so this is familiar:

python
def save_tasks(task_list, filename="tasks.csv"):
    try:
        with open(filename, "w", newline="") as file:
            writer = csv.writer(file)
            for task in task_list:
                writer.writerow([task.title, task.due_date or "", task.completed])
    except OSError as e:
        print(f"Error: could not save tasks ({e}).")

Keep your comments; only the try: / except lines are new, and everything between them gets indented one more level.

One catch in main.py. Your main.py prints Tasks saved! right after calling save_tasks. With the fix, the error message prints, and then Tasks saved! would still print, which is misleading. Two ways around it:

Simplest: move the print("Tasks saved!") into save_tasks, right after the with block, inside the try. Then it only prints on success. Remove it from main.py.
Or have save_tasks return True on success and False on failure, and have main.py print only when it gets True.

Option 1 is less to change.
